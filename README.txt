Publish for free with GitHub Pages:
1. Sign in at https://github.com/
2. Create a new public repository, e.g. jessica-mae-portfolio.
3. Upload index.html and style.css to the repository root.
4. Open Settings > Pages.
5. Choose "Deploy from a branch", branch "main", folder "/(root)", then Save.
6. Wait a few minutes and open the URL shown in Pages settings.
